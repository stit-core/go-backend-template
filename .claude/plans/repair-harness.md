# repair-harness — точная обвязка, живой жизненный цикл шаблона, повторный аудит

## Цель
Третья, завершающая часть программы исправлений по аудиту. Проза обвязки становится точной,
непротиворечивой и проверяемой машиной; форки получают улучшения шаблона; prune не ломает проект.
Итог программы подтверждается повторным аудитом: каждый из 8 углов ≥ 9/10.

## Контекст
- После `harden-gate` и `fix-reference-code`: честный гейт с integration-тестами, archtest
  «границы 2.0», самопроверка ссылок в прозе, исправленный эталон, покрытие ≥ 90%.

  эксперименты для повторного аудита. **Отметки владельца:** `ArtifactData` `list`,
  `collection: review`.
