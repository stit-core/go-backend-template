# _shared — Cross-context Value Objects

Платформенные VO, разделяемые между bounded contexts. Заводим **только когда реально нужно** (DDD-предпочтение — каждый контекст типизирует своё). Сюда попадает только то, что:

1. структурно идентично между ≥2 доменами,
2. не несёт доменной семантики (не относится к ubiquitous language конкретного контекста),
3. в Go-коде ляжет в `internal/platform/<area>/`, а не в `internal/domain/<ctx>/`.

## Purpose

- _что делаем_: даём bounded contexts общий VO-словарь для платформенных значений (storage refs, media-метаданные, и т.п.).
- _чего не делаем_: не помещаем сюда доменные VO (например, `Phone` живёт внутри `iam.User` или `directory.Mosque` — это бизнес-семантика контекста). Не моделируем здесь cross-context **агрегаты** или **events**.
