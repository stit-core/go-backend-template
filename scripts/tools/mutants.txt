# Мутации make mutate (scripts/tools/mutate.py, rule tests-pipeline): правки «было → стало» по тексту кода,
# без номеров строк. Блок мутации:
#
#   ## <id> <слой> — <что ломает>
#   = <почему тесты её не видят>          только у известной эквивалентной
#   <файл от корня репо>
#   - <строка «было»>                     «было» — текст ровно одного места файла, пробелы не важны
#   + <строка «стало»>                    нет строк «+» — место удаляется
#
# Несколько файлов — несколько групп «файл, -, +». Правка кода, которая убрала «было», делает мутацию
# устаревшей: make mutate называет её, прогон не падает — перепиши блок под код.
